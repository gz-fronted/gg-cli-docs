# gg-cli

`@chenhui996/gg-cli` 是团队前端项目初始化工具，命令名为 `gg-cli`。

## 常用方式

```bash
gg-cli init my-app
```

指定包管理器：

```bash
gg-cli init my-app --pm pnpm
```

强制获取最新模板：

```bash
gg-cli init my-app --refresh
```

更多参数见[命令行参数](/cli/commands)。网络或权限异常见[常见问题](/cli/troubleshooting)。
